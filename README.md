# Book Store API with Swagger

A beginner Node.js, Express, and Swagger project.

## Requirements

- Node.js
- npm

## Installation

```bash
git clone https://github.com/YOUR-USERNAME/bookstore-api-swagger.git
cd bookstore-api-swagger
npm install
npm run dev
```

## Swagger Documentation

Open this page after starting the server:

```text
http://localhost:3000/api-docs
```

## API Endpoints

- `GET /books`
- `GET /books/{id}`
- `POST /books`
- `PUT /books/{id}`
- `DELETE /books/{id}`
